# Professional Development Materials

Tools and session materials for teachers of multilingual learners, by Jennifer Hess.

**Website:** https://jenniferhess.info/

## What's here

| Folder | What it is |
| --- | --- |
| [bilingual-packages](bilingual-packages/) | Gemini prompt packages that turn a teacher's own assignment into a scaffolded, stacked English and Spanish worksheet (ELA, History, Science, Math). Changes are listed in its [CHANGELOG](bilingual-packages/CHANGELOG.md). |

## Ground rules for the prompt packages

- Use your district Gemini account.
- Teacher materials only. Never student names or student work.
- Do not edit the prompts. If a prompt misbehaves, save the uploaded file and the output and contact Jennifer Hess: jennifer.hess@hsv-k12.org

## Updating a package

1. Edit the package file in `bilingual-packages/` and change its footer and saved-copy notice to the new version date.
2. Rebuild `bilingual-packages/bilingual-packages.zip` with all four files, named `Bilingual_<Subject>_Prompts.html`.
3. Add a dated entry to `bilingual-packages/CHANGELOG.md`.
