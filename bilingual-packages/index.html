Bilingual Assignment Packages

Prompts that turn a teacher's own assignment into a scaffolded, stacked English and Spanish worksheet: each English line, then its Spanish translation in italics beneath it. Works in Gemini or NotebookLM.

Pick your subject

ELALiterary text stays in English. Essays get an outline frame. HistoryPrimary sources stay in English, with a labeled summary. DBQ and essay outline frames. ScienceLabs, CER conclusion frames, data tables kept blank, calculation setups. MathExpressions in plain text, word problems retold, blank graphing grids. A paper fallback for IXL classes.

How it works

  1. Upload one assignmentStart a new chat. One assignment per upload, answer key removed, the original Doc or Word file rather than a scan.
  2. Paste CHECKIt reads the upload and replies with exactly one next step.
  3. Paste SCAFFOLD, if CHECK says soAdds steps, banks, a model, and sentence frames, in English. Quizzes and tests skip it.
  4. Paste TRANSLATE, then FORMAT HTMLSave the code as an .html file, open it in Chrome, and print to PDF.
  5. Run the teacher checkAt the bottom of every package. About two minutes, before anything prints.

Ground rules

  • Use your district Gemini account.
  • Teacher materials only. Never student names or student work.
  • Do not edit the prompts. Every word is there because a run failed without it. If a prompt misbehaves, save the file and the output and contact Jennifer Hess. Changes are worked on together, and everyone gets the new version here.
